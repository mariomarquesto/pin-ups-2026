# Pin Ups Store 🛒✨

Bienvenido al repositorio oficial de **Pin Ups Store**, un ecommerce de moda inclusiva, talles reales y calzado con diseño especial, basado en San Miguel de Tucumán, Argentina.

## 🚀 Descripción del Proyecto

Este proyecto es una Single Page Application (SPA) desarrollada con **React** que ofrece una experiencia de compra fluida y moderna, enfocada en la comodidad del usuario y la diversidad corporal. El sistema ahora cuenta con un **Panel de Administración completo e integrado con Supabase** para la gestión dinámica de contenidos, catálogo, pedidos y marketing visual.

---

## 🛠 Tecnologías Utilizadas

* **Frontend:** React.js, React-Router-DOM
* **Estilado & UI:** React-Bootstrap, Bootstrap, CSS3 (Animaciones personalizadas)
* **Iconografía:** React-Icons
* **Backend & Base de Datos:** Supabase (PostgreSQL, Storage para imágenes y autenticación de datos)
* **Entorno & Despliegue:** Node.js, Git / GitHub

---

## 📦 Características Principales

### 🛍️ Tienda Pública & Experiencia de Usuario
* **Catálogo Inclusivo:** Enfoque en talles grandes y calzado especial con filtros y detalles de productos.
* **Diseño 100% Responsive:** Adaptado de forma fluida para móviles, tablets y escritorios.
* **Popup Promocional Dinámico:** Ventana emergente configurable desde el panel de administración.
* **Banner y Carrusel (Slider) Dinámicos:** Secciones rotativas adaptadas en tiempo real.
* **Canal Directo:** Integración fluida con WhatsApp para atención personalizada y cierre de pedidos.

### ⚙️ Panel de Administración (Admin Dashboard)
* **Métricas en Tiempo Real:** Control visual de productos activos, pedidos pendientes y ventas totales calculadas automáticamente.
* **Gestión de Productos:** Altura, edición, precios, talles y control de stock.
* **Gestión de Pedidos:** Seguimiento de estados de compra de los clientes.
* **Control Visual Personalizado:** 
  * Subida, ordenamiento y eliminación de imágenes para el **Carrusel Principal**.
  * Personalización del **Banner Promocional** con opción de restablecer al diseño por defecto.
  * Personalización del **Popup de Oferta** con opción de restablecer al diseño por defecto.
